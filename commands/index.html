    Commands¶

    Main¶

    auto_set_syntax¶

    Example

    {
    "caption": "AutoSetSyntax: Auto Set Syntax",
    "command": "auto_set_syntax",
},

    This command tries to set the syntax for the current view.

    Info

    You may consider AutoSetSyntax is kind of working in a way that it checks some prerequisites and triggers the auto_set_syntax command automatically. Although actually, AutoSetSyntax doesn't trigger the command.

    auto_set_syntax_download_dependencies¶

    Example

    {
    "caption": "AutoSetSyntax: Download Dependencies",
    "command": "auto_set_syntax_download_dependencies",
},

    This command downloads the Magika deep-learning detection dependencies. It is the first step of the [Magika setup guide][plugin-magika].

    Example

    "caption": "AutoSetSyntax: Syntax Rules Summary",

},

    This command outputs a summary of all compiled syntax rules for debugging.
